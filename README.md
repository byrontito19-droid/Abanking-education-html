# Antools — учебная вёрстка

**Автор:** Byron Tito. **GitHub:** byrontito19-droid.

Учебная страница по макету [For university course landing](https://www.figma.com/design/jFj70BijeNOjaCI9N6wZZf/For-univrseity-course-landing).
Основа задания: fork [PolFrol/Abanking-education-html](https://github.com/PolFrol/Abanking-education-html).
Платформа: [Abanking Education](https://education-student.abanking.ru/).

## Запуск

Нужен Node.js 18 или новее. Сторонние зависимости для запуска не нужны.

```bash
npm start
```

Откройте http://127.0.0.1:4173 в браузере.

## Сборка

```bash
npm run build
```

Готовые файлы находятся в `dist/`. Исходный код — в `src/`.
Для этого статического задания добавлены простые скрипты запуска и сборки на встроенных модулях Node.js.
Исходный файл webpack.config.js в fork можно сохранить; текущие npm-скрипты его не используют.

## Реализовано

- Шапка, первый экран с поиском, сетка инструментов и блок брендов.
- Адаптация для компьютера, планшета и телефона.
- БЭМ: `tool-card__header`, `tool-card__action_saved`, `header__nav_open`.
- Поиск по названию, фильтры категорий, загрузка дополнительных карточек.
- Избранное и коллекция с сохранением в localStorage.
- Настоящие внешние ссылки, навигация с клавиатуры, подписи кнопок и видимый фокус.
- Диалог персонализации имени на этом устройстве. Это учебная демонстрация без серверной регистрации, паролей или отправки персональных данных.

Текст и основной порядок блоков сохранены по макету. SVG-иллюстрация и логотипы в `src/assets/` воссозданы для учебной работы; это не экспорт исходных графических файлов Figma. Шрифт Poppins загружается из Google Fonts; без интернета используется Arial.

## Проверка вручную

1. Найдите Figma через поиск. Сбросьте фильтр.
2. Выберите категорию Development и проверьте соответствующие карточки.
3. Сохраните инструмент кнопкой папки, откройте My Collections, удалите его.
4. Нажмите Load more, Visit, Login и Sign Up.
5. Проверьте страницу при ширине 1440 и 390 пикселей.

Исторический инструмент Invision сохранён по макету; доступность его внешнего сайта зависит от владельца сервиса.
